New-Project Manifest

What every new buddy automatically gets when it's born.

1 · Side threadThe project's conversational home — all discussion, decisions, and reviews live here.
2 · Product briefCanonical description in Zuki Docs (Google Doc): the idea, the problem, revenue potential, room for growth, v1 scope, open questions.
3 · GitHub repoPrivate repo holding the code — and eventually the knowledge base (KNOWLEDGE.md, DECISIONS.md).
4 · INIT summaryFirst message in the thread: the brief's executive summary (the mission statement), plus links to brief, repo, related docs, parent and children.
5 · Review askQuick-reply widget asking Dave to review the brief — looks good, edits, or defer.
6 · Quick-links entryOne-tap link to the brief, appended to quick-links.md.
7 · Memory entryMEMORY.md bullet: what the project is, key links, current status.
8 · Awaiting-reply entryThe brief review tracked in the registry until Dave answers.

Decided, not yet automatic: a dashboard entry here, and a per-buddy home page view in the sidebar.
